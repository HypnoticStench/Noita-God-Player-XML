Noita God Mina Save

Want to start a Noita run with an extremely powerful Mina?

This repository contains a working player.xml that can be used to start a new run with:

- Effectively infinite HP
- Crown
- 34-orb amulet/gem
- Tinker With Wands Everywhere
- Polymorph immunity
- Expanded inventory
Installation
Back up your Noita save.
Close Noita completely.
Navigate to your Noita save folder.
Replace the appropriate player.xml.
Start Noita.

Always make a backup before replacing save files.

Is this safe?

This repository contains a Noita XML save/entity file. It does not contain an executable program, installer, DLL, or script. You can inspect the XML yourself before using it.
